# SMP-24: open the Melvil app with the customer signed in

Spec: sergen-docs `specs/SMP-24.md` (contract points 3 and 5 of `specs/SERGEN-33.md`).

## Goal

`<shop>/?miguel-open-app=web` (the theme's "read in the app" button) and `<shop>/?miguel-open-app=app`
(the app's sign-in window) ask Miguel's `POST /v2/app-login-links` for a one-time sign-in of the
WordPress customer and redirect to the `openUrl` / `appUrl` it returns.

## Files

- `includes/api/v2/class-miguel-v2-client.php`: `create_app_login_link( $email )` — body
  `{"email": <string|null>}`, short timeout (the visitor waits), returns the decoded body or a
  `WP_Error`. A 200 without string `openUrl` and `appUrl` is reported as `MIGUEL_RESPONSE_INVALID`
  **without** a response excerpt (the body carries the token); errors are reported as by every
  other call.
- `includes/class-miguel-open-app.php` (new): `Miguel_Open_App`, built with the hook manager, the
  v2 client and a responder callable (default: send the headers, the status and the body, then
  exit). On `template_redirect` (priority 0) it reads `$_GET['miguel-open-app']`, builds a response
  array `{status, headers, body}` and hands it to the responder. Unknown values are ignored.
  - `web`: email only when the feature is on, a user is signed in and `wp_is_mobile()`; else `null`.
    Error → 302 to the fallback option (home page when empty).
  - `app`: off → failure page, no call. Signed out → 302 to `wp_login_url( <this url> )`. Signed in →
    302 to `appUrl`; error → failure page "Přihlášení se nepovedlo".
  - Every response: `Cache-Control: no-store, …`, and `DONOTCACHEPAGE` for page-cache plugins. The
    token only ever travels in `Location`; the failure page is static text.
  - The failure page is escaped again at output (`wp_kses`): the WooCommerce sniffer in CI ignores
    `phpcs:ignore` annotations.
  - `url( $mode )` builds the address; `miguel_open_app_url()` and the `[miguel_open_app_url]`
    shortcode give the `web` one to the theme.
- `includes/admin/class-miguel-settings.php`: a new "Open the app" section — the switch
  (`miguel_open_app_enabled`, default `no`) and the fallback URL (`miguel_open_app_fallback_url`).
- `includes/class-miguel.php`: include and register the service (outside tests).
- `languages/*.po`: the new strings.

## Tests (written first)

- `tests/unit/test-open-app.php`: points 1–5 of the criteria through `maybe_handle()` with a
  capturing responder and the HTTP mock (`Miguel_Helper_HTTP`), so the real client and its
  reporting run: the new call's request, its error reports and the token-free report of an
  invalid answer are asserted there.
- `tests/unit/test-settings.php`: the new section and its defaults.
